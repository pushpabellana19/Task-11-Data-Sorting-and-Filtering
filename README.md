
# Task 11 – Basic Data Sorting and Filtering

## Project Overview
This project focuses on sorting and filtering a Retail Sales dataset using Google Sheets to answer important business questions and gain useful insights.

## Tools Used
- Google Sheets
- GitHub

## Dataset Details
The dataset contains retail sales transaction information, including:
- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## Tasks Performed
1. Sorted transactions by Total Amount in descending order.
2. Filtered data by Product Category.
3. Applied gender-based filtering.
4. Used multiple filters to identify specific transactions.
5. Answered five business questions using Google Sheets formulas.

## Business Questions
1. How many female customers purchased Electronics worth more than ₹1,000?
2. Which product category has the highest total sales?
3. Which gender has the highest number of transactions?
4. Which transaction has the highest total amount?
5. How many transactions have a quantity greater than 2?

## Key Findings
- Electronics recorded the highest total sales.
- Female customers had the highest number of transactions.
- Transaction ID 15 had the highest transaction amount.
- 504 transactions had a quantity greater than 2.

## Conclusion
This task helped me understand basic data sorting and filtering techniques in Google Sheets. It also improved my ability to analyze retail sales data and answer business-related questions.
